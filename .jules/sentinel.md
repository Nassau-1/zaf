## 2025-10-24 - Path Traversal in Static File Server
**Vulnerability:** The Node.js application `dashboard/server.js` was vulnerable to Path Traversal in its static file serving logic. It directly used URL paths concatenated with `__dirname` without decoding URL-encoded characters (like `%2e` for `.`) and relied on a weak `.startsWith()` check before resolving the absolute path, allowing an attacker to read arbitrary files using `../` or `%2e%2e/` payloads.
**Learning:** Checking path containment with `.startsWith()` on user-supplied strings *before* decoding them and resolving them to absolute paths with `path.resolve` is insecure because it allows path traversal bytes to bypass the prefix check and traverse outside the root directory when read by `fs.readFile`.
**Prevention:** Always decode URL-encoded input using `decodeURIComponent()`, compute the absolute path using `path.resolve()`, ensure the target directory ends with `path.sep` to prevent partial folder matches (e.g., `/app/dashboard-malicious/`), and perform the `startsWith()` check on the absolute path against the safe directory.
